# AKSESI for LG webOS TV

Installable webOS TV application package source (.ipk), running in the webOS TV application runtime.

Build with webOS TV SDK / CLI (ares-cli): run `ares-package .` from this directory. For testing, enable Developer Mode on the LG TV and install with `ares-install --device <device-name> <package.ipk>`. Test on the actual TV model/webOS version before release.

The generated IPK is a developer/test package; LG Content Store publication requires separate LG developer registration and review.
