# AKSESI for Samsung Smart TV (Tizen)

Installable Tizen TV application source. It launches the AKSESI player in the TV's built-in web runtime.

Build with Samsung TV SDK / Tizen Studio and TV extensions. Create an author certificate and Samsung distributor certificate for the target TV model/year, import the certificate profile, then package this directory as a Tizen Web Application (.wgt). Test on the TV in Developer Mode.

A valid Samsung certificate profile is required for a distributable signed WGT. Do not publish an unsigned build as install-ready.
